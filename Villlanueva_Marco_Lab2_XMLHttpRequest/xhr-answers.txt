1. What is the difference between readyState and status in XMLHttpRequest?

readyState tells us the current stage of the request. It goes from 0 to 4:
  0 - Request not yet opened
  1 - Request opened (open() was called)
  2 - Request sent and headers received
  3 - Response is being downloaded
  4 - Request finished and the response is ready

status is the HTTP status code sent back by the server. It tells us the
result of the request, for example:
  200 - OK (success)
  404 - Not Found
  500 - Internal Server Error

In short, readyState tells us "how far along is the request?", while
status tells us "was the request successful?". We usually check that
readyState === 4 first, then check status === 200.


2. How can you make the request asynchronous?

By setting the third parameter of the open() method to true:

  xhr.open("GET", "https://jsonplaceholder.typicode.com/posts/1", true);

With this setting, the browser sends the request in the background and
keeps running other code. When the response arrives, a function such as
onreadystatechange runs to handle it.


3. Why is asynchronous communication recommended for web applications?

Asynchronous communication is recommended because:
  - The web page does not freeze or become unresponsive while waiting
    for the server.
  - Users can keep clicking, scrolling, and typing while data loads.
  - Only the needed data is loaded, so the whole page does not have to
    reload.
  - It makes the application faster and gives a smoother user experience.
  - Slow servers or slow internet connections do not block the rest of
    the page.
